1. What Is This App?

GOOD EATS is a mobile food ordering app for Christoffel's Restaurant.

Customers can:
- Browse the full menu
- Search for food by name (e.g. burger)
- Filter by Starter, Main Course, Dessert, Drinks
- Add or minus items to their order with + / -
- See their order total live (there is no need to calculate on your own)
- Checkout
- Then after you checkout you will see "your order has been placed"

The Chef can:
- Add a new dish
- Edit an existing dish
- Delete a dish
- Change the price, description and course

It is built to look and feel like a real phone app, not a website. On a laptop it shows in a phone frame (430px wide) with red background. On a real phone it also show which means it accomodates every user
