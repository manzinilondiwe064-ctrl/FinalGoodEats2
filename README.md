Change Log

Changes implemented since Part 2

 Problems in Part 2
- Menu pictures did not match the dish names.
- The chef could not add items to the menu.
- The app was not fully functional.
- The app was not user friendly.

 1. Manage menu items (chef)
- Added: a "Chef – Add / Edit / Delete" screen where the chef can add a dish with a name, description, price, optional picture link (image URL) and course (Starter, Main Course, Dessert or Drinks). This fixes the Part 2 problem where the chef could not add items.
- Added: an Edit button on every dish. It opens the form pre-filled with the dish's current details and picture preview, so any field can be updated.
- Added: a *Delete* button on every dish with an "Are you sure?" confirmation, to prevent accidental deletions.
- Changes (add, edit, delete) show in the app straight away, including on the customer menu and the statistics.

 2. Search and filter
- Added: a search bar on the Home and Menu screens that finds dishes by name.
- Added: search and course filters on the **Chef** screen too, so the chef can quickly find a dish to edit or delete. The dish count updates as you search or filter.
- Added: course filters on the Menu screen: All, Starter, Main Course, Dessert and Drinks.
- Added: selecting **All** clears the filter and shows every dish again.
- Added: Home category shortcuts (Main Course, Starter, Dessert, Drinks) for quick browsing.

3. Menu statistics
- Added: a Stats screen showing the total number of menu items, the average price and the number of drinks.
- Added: a breakdown by course (Main Course, Starter, Dessert, Drinks).
- Added: the current order total.
- Statistics are shown in coloured summary cards so they are easy to read.

 4. Ordering and checkout
- Added: quantity steppers (– / +) on every dish.
- Added: a running order total, and a checkout form for the buyer's details.

 5. Pictures fixed
- Every dish now has a picture that matches its name (for example the Beef Burger shows a burger, Key Lime Pie shows a pie, and the Cinnamon Shake shows a shake).
- Dishes added by the chef can use their own picture link, with a preview.

 6. User experience and design
- Added: a bottom navigation bar with Home, Menu, Drinks, Chef and Stats, so every feature is one tap away.
- Added: a consistent branded header (restaurant name, phone number, location and delivery partners) and a consistent red colour theme on every screen.
- Dishes are laid out as clear cards showing the picture, name, course, description and price in rand (for example R119.00).
- The app is now functional from start to finish: browse, search, order, check out, and manage the menu.
